## 繁體中文

AirShare 是一款讓 iPhone 與 Android 手機透過同一個 Wi-Fi，將照片與影片直接傳送到電腦的工具。不需要帳號、傳輸線、雲端上傳或電腦端程式。

這個倉庫只包含 AirShare 的靜態介紹網站，並透過 GitHub Pages 發布。

### 網站特色

- 清楚呈現 iOS 相簿授權與 Android QR 連線兩種不同畫面
- 說明照片與影片只在使用者的區域網路內傳輸
- 支援繁體中文、英文與日文
- 包含 iOS／Android 功能比較、三步驟使用方式與隱私權政策
- 純 HTML、CSS 與 JavaScript，不需要建置工具或前端框架
- 支援桌面與手機版響應式顯示

### 本機預覽

```bash
python3 -m http.server 8000
```

接著開啟 [http://localhost:8000](http://localhost:8000)。

### 發布

網站由 GitHub Pages 從 `main` 分支根目錄發布：

<https://yenyuy.github.io/AirShare/>

## English

AirShare transfers photos and videos directly from an iPhone or Android phone to a computer on the same Wi-Fi network. It requires no account, cable, cloud upload, or desktop application.

This repository contains only the static AirShare product website published through GitHub Pages.

### Website highlights

- Clearly differentiated iOS photo-permission and Android QR-session previews
- Explains that photos and videos stay on the user's local network
- Complete Traditional Chinese, English, and Japanese content
- Includes platform comparisons, a three-step workflow, and the app privacy policy
- Built with plain HTML, CSS, and JavaScript—no build tool or framework required
- Responsive across desktop and mobile layouts

### Local preview

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

### Deployment

GitHub Pages publishes the website from the root of the `main` branch:

<https://yenyuy.github.io/AirShare/>

## 日本語

AirShareは、同じWi-Fiネットワーク上のiPhoneまたはAndroidスマートフォンから、写真や動画をパソコンへ直接転送するツールです。アカウント、ケーブル、クラウドへのアップロード、パソコン用アプリは必要ありません。

このリポジトリには、GitHub Pagesで公開するAirShareの静的な紹介サイトのみが含まれています。

### サイトの特長

- iOSの写真アクセス許可画面とAndroidのQR接続画面を明確に区別
- 写真や動画がユーザーのローカルネットワーク内だけで転送されることを説明
- 繁体字中国語、英語、日本語に対応
- iOS／Androidの比較、3ステップの使い方、アプリのプライバシーポリシーを掲載
- HTML、CSS、JavaScriptのみで構成され、ビルドツールやフレームワークは不要
- デスクトップとモバイルのレスポンシブ表示に対応

### ローカルプレビュー

```bash
python3 -m http.server 8000
```

続いて[http://localhost:8000](http://localhost:8000)を開きます。

### 公開方法

GitHub Pagesが`main`ブランチのルートからサイトを公開します：

<https://yenyuy.github.io/AirShare/>
